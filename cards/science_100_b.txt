## Science 20 | Dynamics of Ecosystems
What is an ecosystem? :: A community of living things interacting with their non-living environment.
What are biotic factors? :: The living parts of an ecosystem.
What are abiotic factors? :: The non-living parts, like sunlight, water and soil.
Name three abiotic factors. :: Temperature, water, light, soil, wind.
What is a population? :: All individuals of one species in an area.
What is a community? :: All populations in an area.
What is a habitat? :: Where an organism lives.
What is a niche? :: An organism's role and the conditions it needs.
What is the difference between habitat and niche? :: Habitat is the address; niche is the job.
What is a biome? :: A large region with a characteristic climate and living things.
What biome covers most of northern Alberta? :: Boreal forest.
What biome covers southern Alberta? :: Grassland (prairie).
What biome is found in the Rocky Mountains? :: Montane and alpine.
What is tundra? :: A cold, treeless biome with permafrost.
What is a producer? :: An organism that makes its own food.
What is a consumer? :: An organism that eats other organisms.
What is a decomposer? :: An organism that breaks down dead matter.
What is a food chain? :: A single path of energy transfer.
What is a food web? :: Interconnected food chains.
What is a trophic level? :: A feeding level in a food chain.
What is the 10% rule? :: Only about 10% of energy passes to the next level.
What is biomass? :: The total mass of living material.
What is an energy pyramid? :: A diagram of energy at each trophic level.
What is primary productivity? :: The rate producers capture energy.
What is the carbon cycle? :: Carbon moving among air, organisms, oceans and soil.
What is the nitrogen cycle? :: Nitrogen moving among air, soil and organisms.
What is nitrogen fixation? :: Converting N2 into usable forms by bacteria.
What is the phosphorus cycle? :: Phosphorus moving through rocks, soil, water and organisms.
What is the water cycle? :: Evaporation, condensation, precipitation and collection.
What is symbiosis? :: A close long-term relationship between species.
What is mutualism? :: Both species benefit, like bees and flowers.
What is commensalism? :: One benefits and the other is unaffected.
What is parasitism? :: One benefits and the other is harmed.
What is predation? :: One organism hunts and eats another.
What is competition? :: Organisms use the same limited resource.
What is interspecific competition? :: Competition between different species.
What is intraspecific competition? :: Competition within the same species.
What is a keystone species? :: A species that has a large effect on its ecosystem.
Give a keystone species example in Alberta. :: Beaver or wolf.
What is an indicator species? :: A species whose health shows ecosystem condition.
What is an invasive species? :: A non-native species that spreads and causes harm.
What is a native species? :: A species that naturally occurs in an area.
What is succession? :: Gradual change in an ecosystem's community.
What is primary succession? :: Succession beginning on bare rock without soil.
What is secondary succession? :: Succession after a disturbance where soil remains.
What is a pioneer species? :: The first species to colonize an area.
What is a climax community? :: A stable community at the end of succession.
What is a population growth curve? :: A graph of population size over time.
What is exponential growth? :: Growth that increases faster as the population grows (J-shaped).
What is logistic growth? :: Growth that levels off at carrying capacity (S-shaped).
What is carrying capacity? :: The maximum population an environment can support.
What is a limiting factor? :: A resource that restricts population growth.
What is a density-dependent factor? :: A limiting factor affected by population size, like disease.
What is a density-independent factor? :: A limiting factor that acts regardless of density, like fire.
What is bioaccumulation? :: A substance building up in an organism.
What is biomagnification? :: A substance becoming more concentrated up a food chain.
What is eutrophication? :: Nutrient overload causing algae blooms and low oxygen.
What is a wetland's value? :: It filters water, stores floods and supports wildlife.
What is the role of fire in the boreal forest? :: It renews habitat and recycles nutrients.
What is a keystone predator example? :: Wolves in Yellowstone.
What is the impact of the mountain pine beetle? :: It kills pine trees across Alberta and B.C. forests.
What is habitat fragmentation? :: Splitting habitat into small isolated patches.
What is a wildlife corridor? :: A strip of habitat connecting separated areas.
What is conservation? :: Protecting and wisely using natural resources.
What is sustainable resource use? :: Using resources so they last for future generations.
What is an ecological footprint? :: The land needed to support a person's lifestyle.
What is biodiversity? :: The variety of life in an area.
Why is biodiversity important to ecosystem stability? :: Diverse systems can adapt better to change.
What is the greenhouse effect's link to ecosystems? :: Warming changes species ranges and timing of seasons.
What is an environmental impact assessment? :: A study of a project's effects on the environment.

## Science 20 | Chemical Change
What is a mole? :: 6.02 x 10^23 particles of a substance.
What is molar mass? :: The mass of one mole in g/mol.
Find the molar mass of H2SO4. :: 98.09 g/mol
Find the molar mass of CaCO3. :: 100.09 g/mol
Find the molar mass of Mg(OH)2. :: 58.33 g/mol
How many moles in 49 g of H2SO4? :: 0.5 mol
How many grams in 3 mol of NaCl? :: 175.3 g
How many moles in 100 g of CaCO3? :: About 1.0 mol
How many molecules in 0.25 mol of water? :: 1.5 x 10^23
What is stoichiometry? :: Using balanced equations to find amounts in reactions.
What is a mole ratio? :: The ratio of coefficients in a balanced equation.
In 2 H2 + O2 -> 2 H2O, how many mol of water from 4 mol H2? :: 4 mol
In 2 H2 + O2 -> 2 H2O, how many mol of O2 react with 6 mol H2? :: 3 mol
In N2 + 3 H2 -> 2 NH3, how many mol NH3 from 3 mol N2? :: 6 mol
What is the limiting reagent? :: The reactant that runs out first.
What is the excess reagent? :: The reactant left over.
What is the theoretical yield? :: The maximum amount of product predicted.
What is the actual yield? :: The amount of product actually obtained.
What is percent yield? :: (actual / theoretical) x 100%
If the actual yield is 4 g and theoretical is 5 g, what is the percent yield? :: 80%
Why is percent yield less than 100% usually? :: Side reactions, incomplete reactions and losses.
What is an acid? :: A substance that releases H+ in water.
What is a base? :: A substance that releases OH- in water.
What is the pH scale? :: A scale from 0 to 14 for acidity.
What is the pH of a neutral solution? :: 7
What is a strong acid? :: An acid that ionizes completely.
Name three strong acids. :: HCl, HNO3, H2SO4.
What is a weak acid? :: An acid that ionizes only partly.
Name a weak acid. :: Acetic acid (CH3COOH).
What is a strong base? :: A base that dissociates completely, like NaOH.
What is a weak base? :: A base that partly reacts with water, like NH3.
What is neutralization? :: Acid + base -> salt + water.
What is a titration? :: Adding a solution of known concentration to determine another.
What is the equivalence point? :: Where moles of acid and base are equal.
What is an indicator's role in titration? :: Shows the endpoint by changing colour.
What is a buffer? :: A solution that resists pH change.
What is oxidation? :: Loss of electrons.
What is reduction? :: Gain of electrons.
What is a redox reaction? :: A reaction involving electron transfer.
What is an oxidizing agent? :: A substance that gains electrons.
What is a reducing agent? :: A substance that loses electrons.
What is corrosion? :: The oxidation of metals, such as rust.
How is rust prevented? :: Painting, galvanizing or cathodic protection.
What is a galvanic cell? :: A cell that produces electricity from a spontaneous reaction.
What is electrolysis? :: Using electricity to drive a non-spontaneous reaction.
What is electroplating? :: Coating an object with a thin layer of metal using electrolysis.
What is a combustion reaction? :: A fuel reacts rapidly with oxygen releasing heat and light.
What are the products of complete combustion of a hydrocarbon? :: CO2 and H2O.
What are the products of incomplete combustion? :: CO, C (soot) and H2O.
What is activation energy? :: The minimum energy needed to start a reaction.
What is a catalyst? :: A substance that speeds a reaction without being consumed.
What is a reaction rate? :: How fast reactants are used or products formed.
What factors affect reaction rate? :: Temperature, concentration, surface area, catalyst.
Why does higher temperature increase rate? :: Particles collide more often and with more energy.
Why does a higher concentration increase rate? :: More collisions per second.
What is collision theory? :: Reactions occur when particles collide with enough energy and correct orientation.
What is an exothermic reaction? :: A reaction that releases heat.
What is an endothermic reaction? :: A reaction that absorbs heat.
What is a precipitate? :: An insoluble solid formed in a solution.
What is a spectator ion? :: An ion that does not take part in the reaction.
What is a net ionic equation? :: An equation showing only the ions that react.
What is the solubility of most nitrates? :: Soluble.
What is the solubility of most chlorides? :: Soluble except Ag, Pb and Hg(I).

## Science 20 | Changes in Motion
What is speed? :: Distance divided by time.
What is velocity? :: Speed with direction.
What is acceleration? :: The rate of change of velocity.
What is the formula for acceleration? :: a = (v_f - v_i)/t
What is displacement? :: Change in position with direction.
What is a vector? :: A quantity with magnitude and direction.
What is a scalar? :: A quantity with magnitude only.
Name three scalars. :: Distance, speed, mass.
Name three vectors. :: Displacement, velocity, force.
Find speed: 150 m in 10 s. :: 15 m/s
Find the distance: 20 m/s for 6 s. :: 120 m
Find the time: 300 m at 15 m/s. :: 20 s
Find acceleration: 0 to 24 m/s in 6 s. :: 4 m/s^2
Find acceleration: 30 to 10 m/s in 4 s. :: -5 m/s^2
Find final velocity: v_i = 5 m/s, a = 2 m/s^2, t = 3 s. :: 11 m/s
What does a flat line on a d-t graph mean? :: The object is at rest.
What does a straight sloped line on a d-t graph mean? :: Constant velocity.
What does the slope of a d-t graph represent? :: Velocity.
What does the slope of a v-t graph represent? :: Acceleration.
What does the area under a v-t graph represent? :: Displacement.
What is uniform motion? :: Motion at constant velocity.
What is free fall? :: Motion under gravity alone.
What is the acceleration due to gravity? :: About 9.8 m/s^2 downward.
What is air resistance? :: A force opposing motion through air.
What is terminal velocity? :: A constant speed where air resistance balances weight.
What is a force? :: A push or pull on an object.
What is the unit of force? :: Newton (N).
What is a net force? :: The vector sum of all forces on an object.
What is balanced force? :: Forces that cancel, giving zero net force.
What is Newton's first law? :: An object keeps its motion unless acted on by a net force.
What is inertia? :: An object's resistance to changes in motion.
What is Newton's second law? :: F_net = m a
Find the force: m = 5 kg, a = 3 m/s^2. :: 15 N
Find the acceleration: F = 20 N, m = 4 kg. :: 5 m/s^2
Find the mass: F = 30 N, a = 6 m/s^2. :: 5 kg
What is Newton's third law? :: Every action has an equal and opposite reaction.
What is weight? :: The force of gravity on an object.
What is the weight of a 10 kg mass? :: About 98 N
What is the difference between mass and weight? :: Mass is the amount of matter; weight is the gravitational force.
What is friction? :: A force that opposes motion between surfaces.
What is static friction? :: Friction that keeps an object from starting to move.
What is kinetic friction? :: Friction on a moving object.
What is normal force? :: The perpendicular force from a surface.
What is tension? :: The pulling force in a rope or cable.
What is momentum? :: Mass times velocity.
Find the momentum: 5 kg at 4 m/s. :: 20 kg m/s
What is impulse? :: Force times time, equal to the change in momentum.
What is conservation of momentum? :: Total momentum stays the same in a closed system.
Why do seatbelts reduce injury? :: They lengthen the time of stopping, reducing the force.
Why do airbags reduce injury? :: They increase stopping time and spread the force.
What is a collision? :: A brief interaction in which objects exert forces on each other.
What is an elastic collision? :: A collision that conserves kinetic energy.
What is an inelastic collision? :: A collision that does not conserve kinetic energy.
What is kinetic energy? :: Energy of motion, 1/2 m v^2.
What is work? :: Force times displacement.
What is power? :: The rate of doing work.
What is a projectile? :: An object moving through the air under gravity.
What is the path of a projectile? :: A parabola.
Does horizontal velocity change in projectile motion? :: No (ignoring air resistance).
What is the vertical acceleration of a projectile? :: 9.8 m/s^2 downward.
What is circular motion? :: Motion along a circular path.
What is centripetal force? :: The inward force that keeps an object in a circular path.
What is a reference frame? :: A point of view from which motion is measured.
What are crumple zones? :: Car parts designed to absorb impact by deforming.
What are headrests for? :: To prevent whiplash by supporting the head in a rear collision.

## Science 20 | Changing Earth
What is the age of Earth? :: About 4.5 billion years.
What are Earth's layers? :: Crust, mantle, outer core, inner core.
What is the crust? :: Earth's thin, rocky outer layer.
What is the mantle? :: The thick layer of hot, slowly flowing rock.
What is the outer core made of? :: Liquid iron and nickel.
What is the inner core made of? :: Solid iron and nickel.
What is the lithosphere? :: The rigid outer layer including the crust and upper mantle.
What is the asthenosphere? :: The soft layer of the mantle that flows slowly.
What is plate tectonics? :: The theory that Earth's lithosphere is divided into moving plates.
What drives plate movement? :: Convection currents in the mantle, slab pull and ridge push.
What is continental drift? :: The idea that continents move over time.
Who proposed continental drift? :: Alfred Wegener.
What was Pangaea? :: A supercontinent that existed about 300 million years ago.
What evidence supports continental drift? :: Matching coastlines, fossils, rock types and glacial deposits.
What is seafloor spreading? :: New oceanic crust forming at ridges and moving apart.
What is a divergent boundary? :: Plates moving apart.
What is a convergent boundary? :: Plates moving toward each other.
What is a transform boundary? :: Plates sliding past each other.
What is subduction? :: One plate sinking beneath another.
What forms at a convergent boundary between continents? :: Mountain ranges.
How were the Rocky Mountains formed? :: By collision and compression of plates, folding and faulting.
What are volcanoes? :: Openings where magma reaches the surface.
What is magma? :: Molten rock beneath the surface.
What is lava? :: Molten rock on the surface.
What is the Ring of Fire? :: A belt of volcanoes and earthquakes around the Pacific Ocean.
What is an earthquake? :: Shaking caused by sudden release of energy in the crust.
What is a fault? :: A crack in the crust where movement occurs.
What is the focus of an earthquake? :: The point underground where it starts.
What is the epicentre? :: The point on the surface above the focus.
What are P-waves? :: Fast compressional seismic waves.
What are S-waves? :: Slower shear seismic waves.
What are surface waves? :: Slowest, most damaging seismic waves.
What is a seismograph? :: An instrument that records seismic waves.
What does the Richter scale measure? :: The magnitude of an earthquake.
What is a tsunami? :: A large ocean wave caused by an undersea disturbance.
What are the three rock types? :: Igneous, sedimentary and metamorphic.
How is igneous rock formed? :: By cooling of magma or lava.
Give an igneous rock example. :: Granite or basalt.
How is sedimentary rock formed? :: By compaction and cementation of sediments.
Give a sedimentary rock example. :: Sandstone, limestone or shale.
How is metamorphic rock formed? :: By heat and pressure changing existing rock.
Give a metamorphic rock example. :: Marble or slate.
What is the rock cycle? :: The ongoing change of rocks among the three types.
What is weathering? :: The breakdown of rock at Earth's surface.
What is erosion? :: Movement of weathered material by wind, water or ice.
What is deposition? :: Material settling in a new place.
What is a fossil? :: Preserved remains or traces of ancient life.
How do fossils form? :: Burial in sediment and mineralization over time.
What is index fossil? :: A fossil used to date and match rock layers.
What is relative dating? :: Determining order of events without exact ages.
What is the law of superposition? :: In undisturbed layers, older layers are on the bottom.
What is absolute dating? :: Finding the numerical age of rock or fossils.
What is radiometric dating? :: Dating using the decay of radioactive isotopes.
What is half-life? :: Time for half of a radioactive sample to decay.
What is carbon-14 dating used for? :: Dating organic material up to about 50 000 years old.
What is the geologic time scale? :: A timeline of Earth's history divided into eons, eras and periods.
What era are we in? :: The Cenozoic.
When did dinosaurs live? :: The Mesozoic Era.
What is the Burgess Shale? :: A famous Cambrian fossil site in the Rockies.
What is Dinosaur Provincial Park known for? :: Rich dinosaur fossils in Alberta's badlands.
What is the Royal Tyrrell Museum? :: A world-famous paleontology museum in Drumheller, Alberta.
What is a glacier? :: A large body of moving ice.
What is glaciation? :: The advance of ice sheets over land.
What landforms do glaciers make? :: U-shaped valleys, moraines and kettle lakes.
What is an ice age? :: A long period of cooler climate with large ice sheets.
What causes ice ages? :: Changes in Earth's orbit, atmosphere and ocean currents.
What is the mass extinction at the end of the Cretaceous? :: The extinction of dinosaurs about 66 million years ago.
What caused the end-Cretaceous extinction? :: An asteroid impact and volcanic activity.

## Biology 20 | Energy and Matter Exchange in the Biosphere
What is the biosphere? :: The part of Earth where life exists.
What is the cell theory? :: All living things are made of cells, cells are the basic units of life, and cells come from cells.
What is a prokaryote? :: A cell without a nucleus.
What is a eukaryote? :: A cell with a nucleus and organelles.
What is the nucleus? :: The organelle that holds DNA.
What are mitochondria? :: Organelles that make ATP.
What are chloroplasts? :: Organelles where photosynthesis occurs.
What is the cell membrane? :: A selectively permeable barrier around the cell.
What is the cell wall? :: A rigid layer around plant cells.
What are ribosomes? :: Organelles that make proteins.
What is the endoplasmic reticulum? :: A network for making and moving proteins and lipids.
What is the Golgi apparatus? :: An organelle that packages and ships proteins.
What are lysosomes? :: Organelles with enzymes that break down waste.
What is a vacuole? :: A storage organelle; large in plant cells.
What is the cytoplasm? :: The fluid inside a cell.
What is the fluid mosaic model? :: The membrane is a flexible layer of lipids and proteins.
What is a phospholipid? :: A molecule with a hydrophilic head and hydrophobic tails.
What is selective permeability? :: The membrane lets some substances through but not others.
What is diffusion? :: Movement from high to low concentration.
What is osmosis? :: Diffusion of water across a membrane.
What is facilitated diffusion? :: Diffusion through protein channels.
What is active transport? :: Movement against a gradient using energy.
What is endocytosis? :: A cell taking in material by engulfing it.
What is exocytosis? :: A cell expelling material in vesicles.
What is a hypertonic solution? :: One with more solute than the cell.
What is a hypotonic solution? :: One with less solute than the cell.
What is an isotonic solution? :: One with equal solute concentration.
What happens to a cell in hypertonic solution? :: It loses water and shrinks.
What happens to a cell in hypotonic solution? :: It gains water and may burst.
What is plasmolysis? :: Plant cell shrinkage when water leaves the vacuole.
What is turgor pressure? :: Pressure of water inside plant cells that keeps them firm.
What are enzymes? :: Proteins that speed up reactions.
What is a substrate? :: The molecule an enzyme acts on.
What is the active site? :: The part of an enzyme where the substrate binds.
How does temperature affect enzymes? :: Rates rise to an optimum, then fall as the enzyme denatures.
What is denaturation? :: Loss of an enzyme's shape and function.
What is the optimal pH for pepsin? :: About 2 (acidic).
What are macromolecules? :: Large molecules like carbohydrates, lipids, proteins and nucleic acids.
What are carbohydrates for? :: Quick energy and structure.
What are lipids for? :: Long-term energy, insulation and membranes.
What are proteins for? :: Enzymes, structure and transport.
What are nucleic acids for? :: Storing and transmitting genetic information.
What is a monomer of protein? :: An amino acid.
What is a monomer of carbohydrates? :: A monosaccharide.
What is a trophic level? :: A feeding level in a food chain.
What is gross primary productivity? :: Total energy captured by producers.
What is net primary productivity? :: Energy left after producers use some in respiration.
What is the carbon cycle? :: The movement of carbon through living and non-living parts.
What is the nitrogen cycle? :: The movement of nitrogen through air, soil and organisms.
What are nitrogen-fixing bacteria? :: Bacteria that convert N2 into ammonia.
What is the phosphorus cycle? :: Movement of phosphorus through rocks, soil and organisms.
What is the water cycle? :: Movement of water through evaporation, precipitation and flow.
What is a limiting nutrient? :: The nutrient in shortest supply, limiting growth.
What is eutrophication? :: Nutrient enrichment causing algal blooms and oxygen loss.
What is bioaccumulation? :: Build-up of a toxin in an organism over time.
What is biomagnification? :: Toxin concentration increasing up the food chain.
Why do top predators have the most toxin? :: Biomagnification concentrates toxins at higher levels.
What is a decomposer's role in nutrient cycling? :: Returning nutrients to the soil.
What is the greenhouse effect's link to biosphere? :: Extra CO2 warms climate and affects ecosystems.
What is ocean acidification? :: Lower ocean pH from absorbing extra CO2.
What is the role of phytoplankton? :: Producing oxygen and forming the base of marine food webs.

What is population size? :: The total number of individuals.
What is natality? :: The birth rate.
What is mortality? :: The death rate.
What is immigration? :: Individuals moving into a population.
What is emigration? :: Individuals moving out of a population.
What is the formula for population change? :: (births + immigration) - (deaths + emigration)
What is a population growth rate? :: The change in population size per unit time.
What is biotic potential? :: The maximum growth rate with unlimited resources.
What is environmental resistance? :: All factors that limit population growth.
What is exponential growth? :: A J-shaped curve with rapidly rising numbers.
What is logistic growth? :: An S-shaped curve leveling at carrying capacity.
What is carrying capacity? :: The maximum sustainable population size.
What are the phases of logistic growth? :: Lag, exponential, deceleration, plateau.
What is a population crash? :: A rapid decline in population size.

What is a limiting factor? :: A factor that restricts population growth.

What is a transect? :: A line along which organisms are sampled.
What is a sample? :: A subset used to estimate the whole population.
What is an ecological niche? :: The role and requirements of a species in its ecosystem.
What is competitive exclusion? :: Two species can't share the same niche indefinitely.
What is resource partitioning? :: Species divide resources to reduce competition.
What is a fundamental niche? :: The full range of conditions a species could use.
What is a realized niche? :: The actual conditions a species uses given competition.
What is symbiosis? :: A close relationship between species.
What is mutualism? :: Both species benefit.
What is parasitism? :: One benefits and the other is harmed.
What is succession? :: A predictable change in community over time.
What is a pioneer species? :: The first colonizers of a barren area.
What is biodiversity? :: The variety of life in an area.
What is species richness? :: The number of species in an area.
What is species evenness? :: How evenly individuals are spread among species.
What is an indicator species? :: A species whose presence shows environmental health.
What is an invasive species? :: A non-native species that spreads and harms ecosystems.
What is habitat fragmentation? :: Splitting habitat into small isolated areas.
What is a wildlife corridor? :: A habitat strip connecting isolated areas.
What is the Species at Risk Act (SARA)? :: Canadian law protecting endangered species.
What is the effect of the mountain pine beetle? :: Widespread pine mortality, changing forest structure.
What is the human population growth pattern? :: Exponential growth in recent centuries.
What is an age-structure pyramid? :: A graph of the population by age and sex.

## Biology 20 | Photosynthesis and Cellular Respiration
What is the equation for photosynthesis? :: 6 CO2 + 6 H2O + light -> C6H12O6 + 6 O2
What is the equation for cellular respiration? :: C6H12O6 + 6 O2 -> 6 CO2 + 6 H2O + ATP
Where does photosynthesis happen in the cell? :: In chloroplasts.
Where does cellular respiration happen? :: In mitochondria (and cytoplasm for glycolysis).
What are thylakoids? :: Membrane sacs in chloroplasts where light reactions occur.
What is the stroma? :: The fluid in chloroplasts where the Calvin cycle occurs.
What is a granum? :: A stack of thylakoids.
What are the light-dependent reactions? :: Reactions that capture light to make ATP and NADPH and release O2.
What are the light-independent reactions? :: The Calvin cycle, which builds sugar from CO2.
What does the Calvin cycle produce? :: G3P, which forms glucose.
What does photolysis mean? :: Splitting water using light energy.
What is released when water splits? :: Oxygen.
What does chlorophyll absorb best? :: Red and blue light.
Why do leaves look green? :: Chlorophyll reflects green light.
What are accessory pigments? :: Pigments like carotenoids that capture extra light.
What is NADPH? :: An electron carrier used in the Calvin cycle.
What is ATP? :: The cell's energy-carrying molecule.
What is ADP? :: Adenosine diphosphate, the low-energy form.
What is ATP synthase? :: An enzyme that makes ATP using a proton gradient.
What is chemiosmosis? :: Using a proton gradient to make ATP.
What is the electron transport chain? :: A series of proteins passing electrons to make a proton gradient.
What is rubisco? :: The enzyme that fixes CO2 in the Calvin cycle.
What factors affect photosynthesis? :: Light intensity, CO2 concentration, temperature and water.
What is the compensation point? :: Where photosynthesis equals respiration.
What is photorespiration? :: A wasteful process where rubisco uses O2 instead of CO2.
What are C4 plants? :: Plants adapted to hot climates that concentrate CO2.
What are CAM plants? :: Plants like cacti that open stomata at night.
What are stomata? :: Pores in leaves for gas exchange.
What are guard cells? :: Cells that open and close stomata.
What is glycolysis? :: Breaking glucose into two pyruvate in the cytoplasm.
How many ATP does glycolysis net? :: 2
What is the Krebs cycle? :: Reactions in the mitochondrial matrix that release CO2 and capture electrons.
Where does the Krebs cycle occur? :: In the mitochondrial matrix.
Where does the electron transport chain occur in respiration? :: In the inner mitochondrial membrane.
What is the final electron acceptor in aerobic respiration? :: Oxygen.
What is NADH? :: An electron carrier produced in glycolysis and the Krebs cycle.
What is FADH2? :: An electron carrier from the Krebs cycle.
How many ATP are produced per glucose in aerobic respiration? :: About 30 to 36.
What is anaerobic respiration? :: Energy release without oxygen.
What is fermentation? :: ATP production without oxygen using glycolysis.
What is lactic acid fermentation? :: Pyruvate becomes lactate in muscles.
What is alcoholic fermentation? :: Yeast converts pyruvate to ethanol and CO2.
Why does fermentation regenerate NAD+? :: So glycolysis can continue.
Why is aerobic respiration more efficient than fermentation? :: It extracts much more energy from glucose.
What is the role of oxygen in respiration? :: It accepts electrons at the end of the chain.
What is oxygen debt? :: Extra oxygen needed after exercise to clear lactate.
What are the products of the Krebs cycle? :: CO2, NADH, FADH2 and a little ATP.
Why are photosynthesis and respiration complementary? :: The products of one are the reactants of the other.
What is the relationship between mitochondria and chloroplasts? :: Both have their own DNA and are thought to come from ancient bacteria.
What is endosymbiotic theory? :: Mitochondria and chloroplasts originated as engulfed prokaryotes.
How can you measure photosynthesis rate? :: Oxygen production, CO2 uptake or biomass.
Why use a light-limited experiment? :: To test how light intensity affects the rate.
What is a control in an experiment? :: A standard for comparison.
What is the independent variable? :: The variable you change.

## Physics 20 | Oscillatory Motion and Mechanical Waves
What is simple harmonic motion? :: Oscillation where restoring force is proportional to displacement.
What is a restoring force? :: A force pulling an object back to equilibrium.
What is Hooke's law? :: F = -k x
What is the period of a mass-spring system? :: T = 2 pi sqrt(m/k)
What is the period of a pendulum? :: T = 2 pi sqrt(L/g)
Find T: L = 1.0 m, g = 9.8. :: About 2.0 s
Find T: m = 0.5 kg, k = 50 N/m. :: About 0.63 s
Does amplitude affect a pendulum's period? :: Not for small angles.
Does mass affect a pendulum's period? :: No.
What is amplitude? :: Maximum displacement from equilibrium.
What is frequency? :: Cycles per second.
What is period? :: Time for one cycle.
How are period and frequency related? :: f = 1/T
Where is speed maximum in SHM? :: At the equilibrium position.
Where is acceleration maximum in SHM? :: At maximum displacement.
Where is potential energy maximum in SHM? :: At maximum displacement.
What is damping? :: Loss of energy that reduces amplitude.
What is resonance? :: Large oscillations when driven at the natural frequency.
Give an example of resonance. :: A swing pushed in time or the Tacoma Narrows Bridge.
What is a wave? :: A disturbance that transfers energy.
What is a mechanical wave? :: A wave that needs a medium.
What is a transverse wave? :: Particles move perpendicular to the wave direction.
What is a longitudinal wave? :: Particles move parallel to the wave direction.
Give a transverse wave example. :: Waves on a rope.
Give a longitudinal wave example. :: Sound.
What is a pulse? :: A single wave disturbance.
What is wavelength? :: Distance between consecutive crests.
What is wave speed? :: v = f lambda
Find v: f = 5 Hz, lambda = 2 m. :: 10 m/s
Find lambda: v = 340 m/s, f = 170 Hz. :: 2 m
Find f: v = 12 m/s, lambda = 3 m. :: 4 Hz
What is the speed of sound in air at 20 degrees C? :: About 343 m/s.
How does sound speed vary with temperature? :: It increases with temperature.
What is the speed of sound in water? :: About 1500 m/s.
What is the speed of sound in steel? :: About 5000 m/s.
What is a crest? :: The top of a transverse wave.
What is a trough? :: The bottom of a transverse wave.
What is a compression? :: A high-pressure region in a longitudinal wave.
What is a rarefaction? :: A low-pressure region in a longitudinal wave.
What is the principle of superposition? :: Overlapping waves add their displacements.
What is constructive interference? :: Waves add to produce larger amplitude.
What is destructive interference? :: Waves cancel to produce smaller amplitude.
What is a standing wave? :: A stationary pattern from two opposite waves.
What is a node? :: A point of zero amplitude.
What is an antinode? :: A point of maximum amplitude.
What is the fundamental frequency? :: The lowest frequency of a standing wave.
What are harmonics? :: Integer multiples of the fundamental frequency.
What is a closed-pipe resonance? :: Odd harmonics only, with a node at the closed end.
What is an open-pipe resonance? :: All harmonics, with antinodes at both ends.
What is reflection of a wave? :: A wave bouncing at a boundary.
What happens at a fixed end? :: The reflected pulse inverts.
What happens at a free end? :: The reflected pulse is not inverted.
What is refraction of a wave? :: A change in direction when speed changes.
What is diffraction? :: A wave spreading around an obstacle or opening.
What is the Doppler effect? :: A change in observed frequency because of relative motion.
What happens when a source approaches? :: Observed frequency rises.
What happens when a source recedes? :: Observed frequency falls.
What is a sonic boom? :: A shock wave when an object travels faster than sound.
What is pitch? :: How high or low a sound is, related to frequency.
What is loudness? :: Related to amplitude.
What is timbre? :: The quality that distinguishes instruments.
What is the human hearing range? :: About 20 Hz to 20 000 Hz.
What is ultrasound? :: Sound above 20 000 Hz.
What is infrasound? :: Sound below 20 Hz.
What is an echo? :: A reflected sound.
What is sonar? :: Using sound waves to detect objects underwater.
What are beats? :: Variations in loudness from two nearby frequencies.
What is the beat frequency? :: The difference between the two frequencies.
What is a decibel? :: A unit of sound intensity level.
