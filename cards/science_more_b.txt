## Science 30 | Living Systems Respond to their Environment
What are the parts of a neuron? :: Dendrites, cell body, axon and axon terminals.
What is a neurotransmitter? :: A chemical that carries a signal across a synapse.
What is a sensory neuron? :: A neuron carrying information from receptors to the brain or spinal cord.
What is a motor neuron? :: A neuron carrying commands from the CNS to muscles or glands.
What is the central nervous system? :: The brain and spinal cord.
What is the peripheral nervous system? :: Nerves outside the brain and spinal cord.
What does the pituitary gland do? :: Releases hormones that control other glands.
What does the thyroid do? :: Regulates metabolism with thyroxine.
What does adrenaline do? :: Prepares the body for fight or flight.
What causes Type 1 diabetes? :: The pancreas fails to make insulin.
What is DNA replication? :: Copying of DNA before cell division.
What is a recessive allele? :: An allele expressed only when two copies are present.
What is a pedigree? :: A diagram showing the inheritance of a trait in a family.
What is a carrier? :: A person who has one copy of a recessive allele but shows no symptoms.
What is cystic fibrosis? :: A recessive genetic disorder affecting the lungs and digestion.
What is gene therapy? :: Treating disease by altering genes.
What is a stem cell? :: A cell that can develop into many cell types.
What is an antibody? :: A protein made by the immune system to target a specific antigen.
What is an antigen? :: A substance that triggers an immune response.
What is the difference between active and passive immunity? :: Active: your body makes antibodies. Passive: you receive them.

What is a biodegradable material? :: A material broken down by living organisms.
What is a landfill leachate? :: Contaminated liquid draining from waste.
What is recycling's main benefit? :: It saves resources and energy and reduces waste.
What is a heavy metal pollutant? :: A toxic metal like lead or mercury.
What is water treatment? :: Removing contaminants to make water safe.
What is a biofuel? :: Fuel made from living matter, like ethanol.
What is a lifecycle analysis? :: Evaluating a product's environmental impact from production to disposal.

What is a haploid cell? :: A cell with one set of chromosomes.

What is PCR? :: A technique that copies DNA many times.
What is gel electrophoresis? :: A method to separate DNA fragments by size.
What is a restriction enzyme? :: An enzyme that cuts DNA at specific sequences.
What is a recombinant DNA? :: DNA combined from two different sources.

What is intraspecific competition? :: Competition among members of the same species.

What is a logistic growth curve shape? :: S-shaped.

What is gene flow? :: Transfer of alleles between populations.
What is a bottleneck effect? :: A drastic population reduction that reduces genetic diversity.
What is the founder effect? :: A new population starts from a few individuals.
What is speciation? :: The formation of new species.
What is allopatric speciation? :: Species formed by geographic separation.
What is adaptive radiation? :: Rapid evolution of many species from a common ancestor.
What is the human population growth concern? :: Rising resource demand and environmental impact.
What is demographic transition? :: A shift from high birth and death rates to low ones as societies develop.
What is a conservation strategy for endangered species? :: Habitat protection, breeding programs and laws.

## Chemistry 30 | Chemical Equilibrium Focusing on Acid-Base Systems
What is the expression for K for N2 + 3H2 <-> 2NH3? :: K = [NH3]^2 / ([N2][H2]^3)
Are solids and liquids included in K? :: No - only gases and aqueous species.
What does K < 1 mean? :: Reactants are favoured at equilibrium.
What is an ICE table? :: A table of Initial, Change and Equilibrium concentrations.
What does Q mean? :: The reaction quotient, calculated at any time like K.
If Q < K, which way does the reaction shift? :: Toward products.
If Q > K, which way does the reaction shift? :: Toward reactants.
What does increasing pressure do to equilibrium? :: It shifts toward the side with fewer gas moles.
What does increasing temperature do for an endothermic reaction? :: Shifts toward products.
What is Ksp? :: The solubility product constant for a slightly soluble salt.
What is the common ion effect? :: Adding a common ion decreases solubility of a salt.
What is Ka for HA? :: [H3O+][A-] / [HA]
What is the pH of a weak acid solution relative to a strong acid of same concentration? :: Higher (less acidic).
What is a conjugate base? :: What an acid becomes after donating a proton.
What is an amphiprotic substance? :: One that can act as an acid or a base, like water.
What is the Henderson-Hasselbalch idea? :: pH = pKa + log([base]/[acid]) for buffers.
What is the half-equivalence point? :: Where pH = pKa during a weak acid titration.
What is the pH at the equivalence point of a strong acid-strong base titration? :: 7
What is an acid-base indicator range? :: The pH interval where it changes colour.
What is a polyprotic acid? :: An acid that can donate more than one proton, like H2SO4.
