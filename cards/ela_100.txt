## English Language Arts * | Media and Visual Literacy
What is media? :: Means of communicating information, like TV, print and the internet.
What is media literacy? :: The ability to access, analyze and create media.
What is a media text? :: Any product of media, like an ad, film or website.
What is the purpose of media? :: To inform, entertain or persuade.
What is a target audience? :: The group a message is aimed at.
What is bias in media? :: A one-sided presentation.
What is a stereotype? :: An oversimplified idea about a group.
What is propaganda? :: Messages designed to influence beliefs, often one-sided.
What is advertising? :: Promotion of products or ideas.
What are persuasive techniques in ads? :: Testimonials, bandwagon, humour and emotional appeals.
What is a testimonial? :: A statement from someone endorsing a product.
What is a celebrity endorsement? :: A famous person promoting a product.
What is a slogan? :: A catchy phrase for a brand.
What is a logo? :: A symbol that identifies a brand.
What is branding? :: Creating an identity for a product.
What is product placement? :: Showing a brand in a show or film.
What is a headline? :: The title of a news story.
What is clickbait? :: A sensational headline designed to attract clicks.
What is the difference between news and opinion? :: News reports facts; opinion gives views.
What is an editorial? :: An opinion piece by a publication.
What is a primary source? :: An original first-hand source.
What is a secondary source? :: A source interpreting primary sources.
What is a credible source? :: One that is accurate, expert and unbiased.
How do you check a source's credibility? :: Check author, date, evidence, purpose and other sources.
What is fact-checking? :: Verifying claims against reliable sources.
What is misinformation? :: False information shared without intent to deceive.
What is disinformation? :: False information shared on purpose to deceive.
What is fake news? :: False stories presented as real news.
What is a deepfake? :: A fake video or audio created using AI.
What is lateral reading? :: Checking other sources to verify a claim.
What is an echo chamber? :: An environment reinforcing existing views.
What is an algorithm in social media? :: A formula choosing which content you see.
What is a filter bubble? :: Seeing mostly content that matches your preferences.
What is a digital footprint? :: The trail of data you leave online.
What is cyberbullying? :: Bullying using digital platforms.
What is digital citizenship? :: Responsible and ethical use of technology.
What is a privacy setting? :: A control over who sees your information.
What is copyright? :: Legal ownership of creative work.
What is fair dealing in Canada? :: Limited use of works for purposes like education or review.
What is a Creative Commons licence? :: A licence allowing certain uses of a work.
What is composition in an image? :: The arrangement of elements.
What is the rule of thirds? :: Placing key elements along lines dividing the frame into thirds.
What is a focal point? :: The place the eye is drawn to first.
What is a close-up? :: A shot showing a subject up close.
What is a long shot? :: A shot showing a subject far away within a setting.
What is a medium shot? :: A shot from the waist up.
What is a high angle? :: A shot from above, making a subject seem small.
What is a low angle? :: A shot from below, making a subject seem powerful.
What is colour symbolism? :: Colours conveying meaning, like red for danger.
What is lighting's effect? :: It sets mood and focus.
What is contrast in visuals? :: Differences in colour or tone that create emphasis.
What is a caption? :: Text describing an image.
What is a graph's purpose? :: To present data visually.
What is a misleading graph? :: A graph with a distorted scale or omitted data.
What is an infographic? :: A visual presentation of information.
What is a documentary? :: A non-fiction film about real events.
What is a trailer? :: A short preview of a film.
What is editing in film? :: Selecting and arranging shots.
What is a soundtrack's effect? :: It sets mood and emotion.
What is a political cartoon? :: An illustration commenting on current events.
What is caricature? :: Exaggeration of features for effect.
What is satire in media? :: Humour used to criticize.
What is a meme? :: A shared image or idea that spreads online.
What is a podcast? :: An audio series downloaded or streamed.
What is a blog? :: A regularly updated website with posts.
What is a vlog? :: A video blog.
What is a hashtag? :: A tag that groups social media posts by topic.
What is media ownership? :: Who controls media outlets.
What is representation? :: How people and groups are portrayed.
What is a gatekeeper in media? :: A person who decides which stories are published.
What is a point of view in media? :: The perspective from which a story is presented.
What does it mean to deconstruct a media text? :: To analyze how it is built and what it intends.
