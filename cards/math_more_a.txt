Solve: y = x + 3, y = x^2 + 1 :: x^2 - x - 2 = 0, x = 2 or -1: points (2, 5) and (-1, 2).
When does a line not intersect a parabola? :: When the resulting quadratic has a negative discriminant.
Solve: x^2 + x - 6 < 0 :: -3 < x < 2.
Solve: x^2 - 1 >= 0 :: x <= -1 or x >= 1.
Is the point (1, 1) a solution of y > x^2 - 1? :: Yes: 1 > 0.
How do you graph a quadratic inequality? :: Graph the parabola (solid or dashed) and shade inside or outside.
Which side of y < x^2 is shaded? :: Below the parabola.
What is a system of two quadratics? :: Two quadratic equations solved together.
How do you solve a system algebraically? :: Substitution or elimination, then solve the resulting equation.
Find the intersection of y = x^2 and y = 4. :: (2, 4) and (-2, 4).
How many solutions when the line is tangent to a parabola? :: Exactly one.
What does the solution set of an inequality system look like? :: A region on the graph.
Why test a point for inequalities? :: To confirm which side to shade.
Solve: 2x^2 - 8 <= 0 :: -2 <= x <= 2.
How do you write an inequality's solution in interval notation? :: Use brackets for included endpoints and parentheses for excluded ones.

## Mathematics 20-2 | Logical Reasoning
Is the statement "If it rains, the ground is wet" true when it rains and the ground is dry? :: False - a true hypothesis with a false conclusion makes the conditional false.
What is a biconditional statement? :: "p if and only if q" - both p implies q and q implies p.
Negation of "x is even"? :: x is not even.
Give a counterexample: all prime numbers are odd. :: 2 is prime and even.
What is a hypothesis? :: The "if" part of a conditional statement.
What is a conclusion? :: The "then" part.
What is the inverse of "if p then q"? :: "If not p then not q."
Is the converse always true if the conditional is true? :: No.
What is a Venn diagram region for A and B? :: The overlap (intersection).
In a class of 30, 18 play soccer, 15 play hockey, and 5 play both. How many play neither? :: 30 - (18 + 15 - 5) = 2.
What does A' mean? :: The complement of A.
What does the symbol "empty set" mean? :: A set with no elements.
What is a universal set? :: The set of all elements under consideration.
Deductive or inductive: "All mammals breathe air; whales are mammals; so whales breathe air"? :: Deductive.
Inductive or deductive: "The sun has risen every day, so it will rise tomorrow"? :: Inductive.
What is a proof? :: A logical argument showing a statement is always true.
