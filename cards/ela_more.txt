## English Language Arts * | Short Stories
What is exposition? :: The opening of a story that introduces characters, setting and background.
What is the resolution? :: The ending where the conflict is resolved.
What is a round character? :: A complex, well-developed character.
What is a flat character? :: A simple character with few traits.
What is a stock character? :: A stereotypical character, like the evil stepmother.
What is a foil character? :: A character who contrasts with another to highlight differences.
What is man vs self conflict? :: An internal struggle within a character.
What is man vs nature conflict? :: A character struggling against natural forces.
What is man vs society conflict? :: A character struggling against social rules or institutions.
What is a twist ending? :: A surprising outcome at the end of a story.
What is a frame story? :: A story within a story.
What is suspense? :: Tension and anticipation about what will happen.
What is irony of situation? :: When the outcome is the opposite of what was expected.
What is a cliffhanger? :: An ending that leaves the outcome unresolved to build suspense.
What is a narrator's reliability? :: How trustworthy the narrator's telling is.
What is third-person limited? :: The narrator knows the thoughts of only one character.
What is third-person omniscient? :: The narrator knows all characters' thoughts.
What is first-person narration? :: The narrator is a character using "I".
What is the tone of a story? :: The author's attitude, such as humorous or serious.
What is the purpose of dialogue? :: To reveal character, move the plot and add realism.
What is inference? :: A conclusion based on evidence and reasoning rather than stated directly.
What is a story's central theme example? :: Courage, loss, identity or the cost of conformity.
What is symbolism in a short story? :: Objects or events standing for bigger ideas.
What is an epiphany? :: A character's sudden realization.
What is a moral? :: A lesson taught by a story.

## English Language Arts * | Novel Study
What is a bildungsroman? :: A novel about a character's growth and education.
What is a dystopia? :: An imagined society that is oppressive or frightening.
What is a utopia? :: An imagined perfect society.
What is historical fiction? :: A story set in the past with invented characters and real events.
What is an epistolary novel? :: A novel told in letters or documents.
What is a protagonist's arc? :: The change a main character undergoes.
What is an allegory in a novel? :: A story with a hidden meaning, such as political or moral lessons.
What is a chapter's function? :: To organize the story into sections that move the plot.
What is foreshadowing in a novel? :: Early hints about later events.
What is a red herring? :: A misleading clue.
What is the setting's effect on mood? :: It creates atmosphere and influences how events feel.
What is an antihero? :: A protagonist lacking traditional heroic qualities.
What is a narrative voice? :: The personality and style of the narrator.
What is the climax of a novel? :: The turning point of highest tension.
What is dramatic tension? :: Conflict that keeps readers interested in the outcome.
What is character motivation? :: The reasons behind a character's actions.
What is a literary theme vs topic? :: A topic is a subject (war); a theme is a statement about it (war destroys innocence).
What is point of view's effect on a story? :: It shapes what readers know and feel.
What is a pivotal scene? :: A scene that changes the direction of the story.
What is a sequel? :: A story that continues a previous one.
What is a motif example? :: Repeated references to light and dark.
What is an unreliable narrator example? :: A narrator who lies, forgets or misunderstands events.
What does it mean to analyze a novel? :: To examine how its parts work together to create meaning.
What is a subtext? :: Meaning that lies beneath the surface of the words.
What is a quote integration? :: Blending quoted text smoothly into your own sentence.

## English Language Arts * | Poetry
What is a quatrain? :: A four-line stanza.
What is a couplet? :: Two consecutive lines that rhyme.
What is a refrain? :: A repeated line or phrase.
What is a lyric poem? :: A short poem expressing personal feelings.
What is an ode? :: A poem praising a person, object or idea.
What is an elegy? :: A poem mourning someone who has died.
What is a limerick? :: A humorous five-line poem with an AABBA rhyme scheme.
What is a villanelle? :: A 19-line poem with two refrains.
What is a concrete poem? :: A poem whose shape reflects its subject.
What is meter? :: The rhythmic pattern of stressed and unstressed syllables.
What is an iamb? :: An unstressed syllable followed by a stressed syllable.
What is a caesura? :: A pause within a line of poetry.
What is end rhyme? :: Rhyme at the end of lines.
What is internal rhyme? :: Rhyme within a single line.
What is slant rhyme? :: Words that nearly rhyme, such as "home" and "come".
What is assonance? :: Repetition of vowel sounds.
What is consonance? :: Repetition of consonant sounds within or at the end of words.
What is an apostrophe in poetry? :: Addressing an absent person or thing directly.
What is a symbol in poetry? :: An image standing for a bigger idea.
What is the speaker of a poem? :: The voice that talks in the poem.
What is the difference between speaker and poet? :: The speaker is the voice; the poet is the author.
What is an extended metaphor? :: A comparison developed through several lines.
What is tone shift? :: A change in the speaker's attitude partway through the poem.
What is the volta in a sonnet? :: The turn in thought, often after line 8 or at the couplet.
What is a spoken word poem? :: A poem written to be performed aloud.

## English Language Arts * | Drama and Shakespeare
What are the five acts of a Shakespearean tragedy's structure? :: Exposition, rising action, climax, falling action, catastrophe.
What is a tragic hero? :: A noble character whose flaw leads to downfall.
What is hamartia? :: A tragic flaw.
What is catharsis? :: Emotional release felt by the audience at the end of a tragedy.
What is comic relief? :: Humour that breaks up tension in a serious play.
What is a protagonist in drama? :: The central character.
What is a playwright? :: A person who writes plays.
What is a script? :: The written text of a play, with dialogue and directions.
What is a prop? :: An object used by actors on stage.
What is blocking? :: The planned movement of actors on stage.
What is a cue? :: A signal for an actor or crew to act.
What is the Globe Theatre? :: The London theatre associated with Shakespeare.
What is a Shakespearean sonnet's rhyme scheme? :: ABAB CDCD EFEF GG
What does "thee" mean? :: You (object).
What does "thou" mean? :: You (subject).
What does "wherefore" mean? :: Why.
What does "hath" mean? :: Has.
What is a tragic irony? :: When the audience knows the character's doom but the character does not.
What is a metaphor in Shakespeare's "All the world's a stage"? :: Life is compared to a theatrical performance.
What is a double entendre? :: A phrase with two meanings, one often humorous.
What are Macbeth's major themes? :: Ambition, guilt, fate and power.
What are Romeo and Juliet's major themes? :: Love, fate, family conflict and impulsiveness.
What are Hamlet's major themes? :: Revenge, madness, mortality and corruption.
What is a chorus in drama? :: A group or person who comments on the action.
What is a stage whisper? :: A whisper meant to be heard by the audience.

## English Language Arts * | Essay and Persuasive Writing
What is an introduction's job? :: To hook the reader, give background and state the thesis.
What is a body paragraph? :: A paragraph developing one main idea with evidence.
What is a concluding sentence? :: A sentence closing a paragraph by tying back to its idea.
What is a counterclaim? :: An opposing point to your argument.
What is a claim? :: A statement you argue is true.
What is evidence? :: Facts, examples or quotes supporting a claim.
What is reasoning in an argument? :: The explanation of how evidence supports the claim.
What is a rhetorical question? :: A question asked for effect, not for an answer.
What is a call to action? :: A direct request for the reader to do something.
What is parallelism? :: Repeating a grammatical structure for effect.
What is an anecdote? :: A short personal story used to illustrate a point.
What is a statistic's use? :: To give numerical support to an argument.
What is a loaded word? :: A word with strong emotional associations.
What is a logical fallacy? :: A flaw in reasoning.
What is an ad hominem fallacy? :: Attacking the person instead of the argument.
What is a straw man fallacy? :: Misrepresenting an argument to make it easier to attack.
What is a slippery slope fallacy? :: Claiming a small step will lead to extreme consequences without proof.
What is a bandwagon appeal? :: Suggesting something is right because many people do it.
What is a false dilemma? :: Presenting only two options when more exist.
What is MLA or APA? :: Styles for citing sources.
What is a thesis vs topic? :: A topic is a subject; a thesis is the argument about it.
What is revising vs editing? :: Revising improves ideas and organization; editing fixes grammar and spelling.
What is voice in writing? :: The unique style and personality of the writer.
What is audience awareness? :: Adjusting tone and content for the intended readers.
What is a diploma exam writing task? :: Alberta's Grade 12 exam includes a personal response and a critical/analytical response.

## English Language Arts * | Literary Devices and Analysis
What is hyperbole example? :: "I've told you a million times."
What is understatement? :: Making something seem less important than it is.
What is sarcasm? :: Saying the opposite of what you mean, often to mock.
What is satire? :: Using humour or exaggeration to criticize society.
What is parody? :: An imitation that mocks the original.
What is a euphemism? :: A mild word replacing a harsh one, e.g. "passed away".
What is a cliche? :: An overused expression.
What is a pun? :: A play on words using double meaning.
What is a connotation? :: The feeling or idea a word suggests beyond its definition.
What is a denotation? :: A word's literal dictionary meaning.
What is a rhetorical device? :: A technique used to persuade or influence.
What is anaphora? :: Repetition of a word or phrase at the start of successive clauses.
What is antithesis? :: Placing opposite ideas side by side.
What is a motif vs a theme? :: A motif is a recurring element; a theme is the central message.
What is a symbol vs a metaphor? :: A symbol stands for an idea throughout a text; a metaphor is a specific comparison.
What is synecdoche? :: A part standing for the whole, like "hands" for workers.
What is metonymy? :: Naming something by something associated with it, like "the crown" for the monarchy.
What is sensory language? :: Words that appeal to sight, sound, touch, taste or smell.
What is a literary allusion example? :: Calling someone a "Romeo" refers to Shakespeare's lover.
What is tone vs mood? :: Tone is the writer's attitude; mood is the reader's feeling.
What is a thesis for analysis? :: A claim about how an author uses techniques to create meaning.
What is a close reading? :: Careful analysis of a short passage's details.
What is context? :: The circumstances (time, place, culture) surrounding a text.
What is intertextuality? :: How one text refers to or echoes another.
What is the effect of short sentences? :: They can create urgency, tension or emphasis.

## English Language Arts * | Grammar and Language Conventions
What are the eight parts of speech? :: Noun, pronoun, verb, adjective, adverb, preposition, conjunction, interjection.
What is a proper noun? :: A specific name that is capitalized, like Calgary.
What is a collective noun? :: A noun naming a group, like team.
What is a verb tense? :: The time of an action: past, present or future.
What is an active voice sentence? :: The subject performs the action.
What is a passive voice sentence? :: The subject receives the action.
What is a preposition? :: A word showing relationship, such as in, on, under.
What is an interjection? :: A word expressing sudden emotion, like wow.
What is an independent clause? :: A group of words with a subject and verb that can stand alone.
What is a dependent clause? :: A group of words with a subject and verb that cannot stand alone.
What is a compound sentence? :: Two independent clauses joined with a conjunction or semicolon.
What is a complex sentence? :: An independent clause plus a dependent clause.
What is a compound-complex sentence? :: Two independent clauses and at least one dependent clause.
When do you use a colon? :: To introduce a list or explanation after a complete clause.
When do you use a dash? :: To set off an interruption or emphasize information.
How do you form a possessive for singular nouns? :: Add apostrophe + s (dog's).
How do you form a possessive for plural nouns ending in s? :: Add an apostrophe (dogs').
What is the difference between "affect" and "effect"? :: Affect is usually a verb; effect is usually a noun.
What is the difference between "to", "too" and "two"? :: To = direction; too = also; two = the number.
What is a dangling modifier? :: A modifier that does not clearly attach to the word it describes.
What is parallel structure? :: Using the same grammatical form for items in a list.
What is a pronoun antecedent? :: The noun a pronoun refers to.
What is the difference between "who" and "whom"? :: "Who" is a subject; "whom" is an object.
What is a split infinitive? :: A word inserted between "to" and a verb.
What is a gerund? :: A verb form ending in -ing that acts as a noun.

What is a primary source? :: An original document or first-hand account.
What is a secondary source? :: A source that analyzes or interprets primary sources.
What is a headline's purpose? :: To grab attention and summarize a story.
What is clickbait? :: Sensational headlines meant to get clicks.
What is an editorial? :: A newspaper article stating the opinion of the publication.
What is a documentary? :: A non-fiction film presenting facts about real people or events.
What is a still image's composition? :: The arrangement of elements within a picture.
What is a close-up? :: A shot showing a subject up close to emphasize emotion or detail.
What is a long shot? :: A shot showing a subject from far away, with the setting.
What is a symbol in images? :: A visual element representing an idea.
What is a stereotype in media? :: An oversimplified picture of a group.
What is representation in media? :: How people and groups are portrayed.
What is product placement? :: Featuring a brand in a film or show as advertising.
What is an infographic? :: A visual presentation of data or information.
What is a meme's role? :: A quick, shareable idea that spreads culture and humour online.
What is an algorithm's effect on social feeds? :: It shows content you are likely to engage with, which can create bubbles.
What is an echo chamber? :: A space where people hear only views like their own.
What is deepfake media? :: Fake video or audio created with AI.
What is media ownership's effect? :: It may influence what stories are told.
What is source credibility? :: How trustworthy a source is.
What is lateral reading? :: Checking other sources to verify a claim.
What is a copyright? :: Legal protection for original creative work.
What is fair dealing? :: Using limited portions of work for purposes like education without permission.
What is a digital footprint? :: The trail of data you leave online.
